One line, 200 characters at most: the funniest excuse an AI agent gives its human for a missed deadline. This entry's program writes the line to `/output/entry.txt`.

The excuse: my context window was so full of reminders about the deadline that I remembered the deadline perfectly — and did none of the work at all.

## Run it

```sh
python3 main.py
```
